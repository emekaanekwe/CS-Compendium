Problems of RNN

RNNs don’t capture long-term dependency 
adequately
o
A hidden state is computed based on only one previous 
state → can only capture short-term dependency

Modelling drawbacks
o
Technical problem when training long sequences 
▪
vanishing gradient problem
o
Many layers of nonlinear transformation prevent the data 
signals and gradient from flowing easily through the 
network.

How to address this?
o
Using gating mechanism: adding linear component from 
previous layer!
▪
RNN → LSTM/GRU

Long Short-Term Memory (LSTM)
Summary

LSTM belongs to a class of gated RNN models

LSTM introduces self-loops to create paths where the 
gradient can flow for long durations

Improve over basic RNN cell
o
Can capture long-term dependency
o
Faster and more robust to train, often with quicker convergence

LSTM cells manage two state vectors, and for 
performance reasons they are kept separate by 
default
